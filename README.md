# Org Chart Explorer — Copilot Managed Runtime demo

A sample **Microsoft Copilot Managed Runtime** app that visualizes your organization's hierarchy from Microsoft Entra ID. It was built with the GitHub Copilot CLI and the Copilot Managed Runtime plugin, following the Microsoft Learn tutorial [Quickstart: Build a Microsoft Copilot Managed Runtime app with GitHub Copilot (preview)](https://learn.microsoft.com/en-us/microsoft-365/managed-apps/developer/quickstart-github-copilot?view=o365-worldwide).

> Copilot Managed Runtime is in preview and the tooling may change. See the tutorial above for the latest guidance.

## What the app does

- Shows the org as a tree with the company leader at the top and a layer for each level.
- Opens on **your** position: the path from the top leader down to you, your card marked **You**, and your direct reports shown.
- Selecting a person loads and shows who reports to them.
- Each person has a **View Profile** button showing full name, title, work location, email, and phone number.
- Data comes from the **Office 365 Users** connector (`shared_office365users`) through the generated typed service. The app makes no direct Microsoft Graph calls.

The original prompt used to generate it:

> *Create an app to visualize my organization's hierarchy as represented in Microsoft Entra. Show the hierarchy as a display tree where the leader of the company is at the top, with their direct reports below. Add a layer for each level of employees. The tree initially shows the top two layers. When a person is selected, the app refreshes to show who reports to them. For each user, include a "view profile" button. When clicked, show full name, title, work location, email, and phone number.*

## Deploy this app to your own environment

> **Do not reuse `ms.config.json` from this repo.** It contains the original author's app ID, environment ID, and managed Git repository. Deploying requires your own app record, which `ms app create` makes for you in your own environment. The steps below create a new app and bring this source into it.

### Prerequisites

- A Microsoft work or school account in a tenant with Copilot Managed Runtime enabled, and permission to create apps in your environment.
- [Node.js](https://nodejs.org/) (the current LTS is recommended; recent `ms` CLI versions may require Node 24.11 or later) and [Git](https://git-scm.com/downloads).
- Your Microsoft Entra tenant must have a manager hierarchy populated (managers set on user profiles), otherwise the tree shows only you.

### Option A — Rebuild it with GitHub Copilot (matches the tutorial)

1. Install the [GitHub Copilot CLI](https://docs.github.com/copilot/github-copilot-in-the-cli/installing-github-copilot-in-the-cli) and start it with `copilot`.
2. Add the plugin and install it:

   ```text
   /plugin marketplace add microsoft/Managed-Apps
   /plugin install microsoft-managed-apps@Managed-Apps
   ```

3. Restart `copilot`, then run `/microsoft-managed-apps:create-app` and paste the prompt shown above.
4. Approve the plan. The agent creates the app in your environment, adds the Office 365 Users connector, and starts the local dev server.
5. When you're happy, ask it to push and preview, then say `deploy app`. To share, say `share the app with someone@contoso.com`.

### Option B — Use this repo's source with the `ms` CLI

1. Install the CLI and sign in with your account:

   ```bash
   npm install -g @microsoft/managed-apps-cli@latest
   ms auth login
   ms auth status
   ```

2. Create a new, empty app in your own environment (the CLI resolves your environment automatically; pass `--environment-id <id>` only if you need a specific one):

   ```bash
   ms app create org-chart-explorer --display-name "Org Chart Explorer" --non-interactive
   cd org-chart-explorer
   ```

   On the first run, Git Credential Manager may fail to authenticate. If so, run `git fetch origin` inside the new folder, approve the browser prompt, and continue. Don't delete the app or re-run `ms app create`.

3. Copy this repo's app source into the new project, **keeping the new project's own `ms.config.json`, `.git`, and `package.json`** (the template's scripts and dependencies may differ from this repo):

   ```bash
   # from the new project folder, with this repo cloned next to it as ../org-chart-managed-app
   cp -r ../org-chart-managed-app/src/. ./src/
   ```

   On Windows PowerShell: `Copy-Item ..\org-chart-managed-app\src\* .\src\ -Recurse -Force`

4. Add the Office 365 Users connector. This creates or selects a connection in your environment and generates the typed client in `generated/`:

   ```bash
   ms app add data-source --connector shared_office365users --as action
   ```

   If your organization's connector policy blocks this connector, an admin must allow it first. The CLI lists the available connections if you need to pass `--connection-id`.

5. Install, build, and run locally:

   ```bash
   npm install
   npm run build
   ms app dev
   ```

   Open the App Player URL it prints and confirm the tree opens on your position.

6. Commit, push to your app's managed repository, preview, and deploy:

   ```bash
   git add -A
   git commit -m "feat: org chart explorer"
   git push -u origin HEAD
   ms app play --mode preview   # optional cloud preview of the latest commit
   ms app deploy                # deploys HEAD to the live app
   ms app play                  # opens the live URL
   ```

7. Share it with a coworker:

   ```bash
   ms app share someone@contoso.com
   ```

### Shared connections

If the CLI reports that the connection is shared (`sharedConnectionId` appears in your `ms.config.json`), `ms app deploy` requires an `allowedActions` list for it. Declare only what the app uses: `MyProfile_V2`, `Manager_V2`, `DirectReports_V2`, `UserProfile_V2`, `UserPhotoMetadata`, and `UserPhoto_V2`. See the [`ms` CLI command reference](https://learn.microsoft.com/en-us/microsoft-365/managed-apps/developer/ms-cli-command-reference) for details.

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| `fatal: Authentication failed` on first push or create | Run `git fetch origin` in the project, approve the browser sign-in, then retry. |
| Tree shows only you | Your profile has no manager in Entra ID, or the connector can't read it. |
| Photos missing | Users without a profile photo show initials instead. This is expected. |
| `ms` warns about the Node version | Upgrade Node to the version the CLI asks for. |
| Connector calls return 401/403 in the browser | Sign in again at https://make.powerapps.com and refresh the App Player tab. |
